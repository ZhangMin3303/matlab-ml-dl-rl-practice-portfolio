# 代码修复记录

## 背景

本项目原始代码可以完成 Iris 数据集可视化和 KNN 分类。为了便于批处理验证、归档和 GitHub 展示，本次做了少量可复现性整理。

## 修复内容

### 1. 增加结果输出目录

新增：

```matlab
resultsDir = fullfile(fileparts(mfilename('fullpath')), 'results');
if ~isfolder(resultsDir)
    mkdir(resultsDir);
end
```

影响：

- 自动保存运行结果。
- 不改变算法逻辑。

### 2. 保存可视化图片

新增 `exportgraphics(...)`，分别保存：

```text
results/iris_2d_scatter.png
results/iris_3d_scatter.png
results/iris_knn_prediction.png
```

影响：

- 方便后续写 README、简历项目说明和 GitHub 展示。

### 3. 保存结果变量

新增 `.mat` 结果文件：

```text
results/iris_2d_scatter_data.mat
results/iris_3d_scatter_data.mat
results/iris_knn_result.mat
```

影响：

- 方便复核数据、准确率和预测结果。

### 4. 固定随机种子

在 `iris_knn.m` 中新增：

```matlab
rng(1);
```

影响：

- 保证训练/测试集划分可复现。

### 5. 输出文本改为 ASCII

将准确率输出改为：

```matlab
fprintf('Test accuracy: %.2f%%\n', accuracy * 100);
```

影响：

- 避免中文日志在 PowerShell 中出现乱码。
