# Publication Notes

## Public Version Policy

This repository was prepared as a slim, public GitHub version of a larger local MATLAB practice folder.

The public version keeps:

- MATLAB source scripts.
- Necessary small local data files.
- Documentation and code notes.
- Run logs that demonstrate local verification.
- Representative figures and selected result summaries.
- One representative CartPole DQN saved agent: `Agent200.mat`.

The public version excludes:

- Original course reports with personal or course metadata.
- Original compressed archives.
- The friend/reference project folder.
- Repeated saved-agent checkpoints.
- Large generated `.mat` result files unless needed for reproducibility.

## Friend Reference Material

The original local folder contains a sixth project based on friend/reference material. It is intentionally not included here because it is not my independent project and should not be presented as such.

## CartPole Checkpoints

The local archive contains many `Agent*.mat` checkpoint files. For GitHub, only `Agent200.mat` is included as a representative final checkpoint so that the verification script remains runnable without making the repository unnecessarily large.

## Course Report Exclusion

The digit recognition course project originally had a course report and compressed data archive. The report is excluded from this public repository because it may contain personal and course-related information. The data needed by the runnable scripts is included directly as small `.mat` files.
