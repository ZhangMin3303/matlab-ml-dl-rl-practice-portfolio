# 代码修复记录

## 背景

本项目原始代码用于 MATLAB 自带 `DigitDataset` 的数字分类练习，包含 MLP 和 CNN 两个模型。为了让代码适合批处理验证、后续归档和 GitHub 展示，本次做了少量可复现性和结果可读性修复。

## 修复内容

### 1. 关闭训练图形窗口

原代码使用：

```matlab
'Plots','training-progress'
```

这会打开训练进度窗口，不适合批处理验证。

已改为：

```matlab
'Plots','none'
```

影响：

- 不改变模型结构。
- 不改变训练数据。
- 只改变运行显示方式。

### 2. 增加 DigitDataset 存在性检查

新增：

```matlab
if ~isfolder(digitDatasetPath)
    error('DigitDataset not found: %s', digitDatasetPath);
end
```

影响：

- 如果 MATLAB 环境缺少该数据集，会给出清晰报错。

### 3. 保存结果文件

新增 `results/` 输出目录，并保存：

- `accuracy`
- `YPred`
- `YTest`

影响：

- 便于后续复核、写 README、做结果分析。

### 4. MLP 训练设置修复

原 MLP 版本测试准确率约为 `10.20%`，接近随机猜测，说明训练设置不适合作为有效 demo。

修复方式：

- 移除异常偏高的 `WeightLearnRateFactor` 和 `BiasLearnRateFactor`。
- 移除重复的 ReLU 层。
- 将优化器从 SGDM 改为 Adam。
- 学习率设为 `0.001`。

修复后结果：

```text
Test accuracy: 75.48%
```

影响：

- 模型仍然是 MLP/全连接神经网络。
- 修复后更适合作为 CNN 的对照基线。

### 5. 输出文本改为 ASCII

原中文输出在 PowerShell 日志中可能出现编码乱码。

已改为：

```matlab
fprintf('Test accuracy: %.2f%%\n', accuracy*100);
```

影响：

- 不改变算法。
- 日志更易读。
