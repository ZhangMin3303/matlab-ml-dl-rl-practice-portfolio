# shuzishibie99.m 代码说明

## 目的

这是 `shuzishibie9.m` 的同类/备份版本，用于训练全连接神经网络识别 10x10 数字矩阵。

## 核心流程

1. 从上一级目录的 `data/` 文件夹加载数字矩阵。
2. 将每个数字矩阵展开为 100 维向量。
3. 构建 12 类分类任务：`0-9`、噪声数字 `1`、噪声数字 `2`。
4. 使用一个隐藏层为 32 个神经元的全连接神经网络进行训练。
5. 使用训练后的网络进行分类并计算准确率。

## 核心算法/技术点

- 全连接神经网络
- ReLU 非线性激活
- Softmax 分类
- SGDM 训练
- MATLAB Deep Learning Toolbox
- 相对路径数据加载
