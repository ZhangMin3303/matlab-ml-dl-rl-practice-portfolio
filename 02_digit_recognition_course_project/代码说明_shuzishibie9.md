# shuzishibie9.m 代码说明

## 目的

训练一个简单的全连接神经网络，对 10x10 数字矩阵进行分类识别。识别类别包括标准数字 `0-9`，以及带噪声的数字 `1` 和 `2`。

## 核心流程

1. 从 `data/` 文件夹加载 `.mat` 数字矩阵。
2. 将每个 10x10 矩阵转成长度为 100 的向量。
3. 将 12 个样本整理成神经网络输入格式 `[1, 100, 1, 12]`。
4. 构建包含一个隐藏全连接层的神经网络。
5. 使用 SGDM 优化器训练模型。
6. 使用同一批样本进行预测并计算准确率。

## 核心算法/技术点

- 全连接神经网络
- ReLU 激活函数
- Softmax 多分类输出
- MATLAB `trainNetwork`
- MATLAB `categorical` 标签
- 基于矩阵展开的数字特征表示
