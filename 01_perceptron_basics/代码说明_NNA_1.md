# NNA_1.m 代码说明

## 目的

演示阈值神经元在多轮样本输入下的权重更新过程，观察权重向量随迭代次数逐步变化。

## 核心算法

- 使用线性净输入：
  - `net = W' * X`
- 使用阈值激活函数：
  - `net >= T` 输出 `1`
  - `net < T` 输出 `-1`
- 使用输出驱动的权重更新：
  - `W = W + n * output * X`

## 技术要点

- `T` 是阈值。
- `n` 是学习率。
- `k` 用于累计迭代次数。
- 脚本每轮依次输入 3 个样本，并将迭代次数累加 3。
- 与标准有监督感知器不同，这里没有显式目标标签 `d` 和误差项 `error`，更像课堂中对阈值神经元更新过程的演示。
