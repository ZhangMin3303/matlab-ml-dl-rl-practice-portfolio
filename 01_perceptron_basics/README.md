## 文件说明

- `class1_1.m`：单层感知器基础示例，展示净输入、符号激活、误差计算和权重更新。
- `class1_2.m`：带偏置项的二分类感知器练习，用于学习线性可分样本的分类边界。
- `NNA_1.m`：阈值神经元/感知器式权重更新练习，演示多轮样本循环下权重变化。
- `NNA_class1_2.m`：与 `class1_2.m` 相近的单层感知器作业版本。

## 直接运行方式

在 MATLAB 中进入本文件夹后运行：

```matlab
run('class1_1.m')
run('class1_2.m')
run('NNA_1.m')
run('NNA_class1_2.m')
```
