# class1_1.m 代码说明

## 目的

演示单层感知器对 3 个手工样本进行一次顺序训练，观察每个样本输入后净输入、输出、误差和权重向量的变化。

## 核心算法

- 使用线性净输入：`net = W' * X`
- 使用符号阈值激活函数：
  - `net >= 0` 输出 `1`
  - `net < 0` 输出 `-1`
- 使用感知器更新规则：
  - `W = W + n * error * X`
  - `error = d - o`

## 技术要点

- `n` 是学习率。
- `X1`、`X2`、`X3` 是输入样本向量。
- `d1`、`d2`、`d3` 是目标类别标签。
- 脚本重点是展示感知器如何根据分类误差调整权重。
